# 微信开发者工具本地联调

## 当前开发地址

- 小程序 API：`http://192.168.31.55:8080/api/v1`
- Admin：`http://192.168.31.55:8080/`
- uni-app 源码目录：`apps/miniapp`
- 微信开发者工具实际导入目录：`apps/miniapp/dist/dev/mp-weixin`

微信开发者工具不能直接运行 uni-app 源码。先在项目根目录执行：

```bash
npm run dev:miniapp
```

等待控制台显示编译完成后，导入 `dist/dev/mp-weixin`。开发进程需要在
联调期间持续运行。

## 微信开发者工具设置

1. 使用项目真实 AppID；暂时没有 AppID 时选择测试号/游客模式。
2. 打开“详情 → 本地设置”。
3. 勾选“不校验合法域名、web-view（业务域名）、TLS版本以及HTTPS证书”。
4. 清除缓存并重新编译。

开发环境使用局域网 HTTP 地址，上述选项仅限本地联调。生产环境继续使用
HTTPS和微信公众平台配置的合法域名。

## 联调顺序

1. 打开小程序并进入“我的”。
2. 使用租户 `DEFAULT` 和联调客户手机号获取验证码；开发验证码会自动填入。
3. 浏览首页、分类、商品列表和商品详情，确认客户价格与库存单位。
4. 将按件或称重商品加入采购单。
5. 首单商品金额需要达到500元后提交订单。
6. 打开Admin并使用仓库联调账号登录。
7. 在订单管理查看新订单。
8. 执行仓库审核，确认小程序订单状态更新。

如果电脑局域网IP发生变化，需要更新 `.env.development` 中的
`VITE_API_BASE_URL`，然后重启小程序开发进程。
